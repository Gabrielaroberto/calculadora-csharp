# Calculadora — C#

Aplicação de consola desenvolvida em C# para realizar operações matemáticas básicas e potenciação.

## Sobre o projeto

Projeto académico desenvolvido no âmbito do estudo de programação em C#. A aplicação apresenta um menu interativo que permite ao utilizador selecionar operações matemáticas e introduzir os valores pretendidos.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Potenciação
- Validação de valores numéricos
- Prevenção de divisão por zero
- Menu interativo com possibilidade de realizar várias operações

## Tecnologias utilizadas

- C#
- .NET
- Visual Studio

## Conceitos de programação aplicados

- Métodos
- Estruturas condicionais (`if` e `switch`)
- Ciclos de repetição (`while`)
- Tipos de dados e variáveis
- Validação de entradas com `double.TryParse()`
- Utilização da classe `Math`

## Como executar

1. Clonar ou descarregar este repositório.
2. Abrir o ficheiro `Calculadora.csproj` no Visual Studio.
3. Executar a aplicação.

## Contexto académico

Projeto desenvolvido para praticar lógica de programação, estruturas de controlo, métodos e validação de dados em C#.
